# 1D Gross–Pitaevskii ground state

This is the SRS fixture for the independently reproducible public example at [github.com/0jg/bec-ground-state](https://github.com/0jg/bec-ground-state). The fixture keeps the solver, experiment configurations, computed outputs, and generated SRS run records together so the public demo can be reviewed without a database.

The solver uses dimensionless harmonic-oscillator units and solves

$$\left[-\frac{1}{2}\frac{d^2}{dx^2}+V(x)+g|\psi(x)|^2\right]\psi(x)=\mu\psi(x),\qquad \int |\psi(x)|^2\,dx=1.$$

For the non-interacting harmonic reference ($$V(x)=x^2/2$$, $$g=0$$), the exact ground-state energy and chemical potential are both $$1/2$$. This is the numerical validation case. The supplied solver implements split-step imaginary-time propagation and normalized finite-difference gradient flow. It reports the norm error, energy, chemical potential, iteration count, and a stationary-equation residual. The residual uses a second-order finite-difference stencil, so it has a spatial-discretization floor even for the Fourier split-step method.

## Reproduce the public example

```sh
git clone https://github.com/0jg/bec-ground-state.git
cd bec-ground-state
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python reproduce.py
```

The individual experiment commands and parameters are listed in `experiments/*.json`. For one run, use:

```sh
python run.py --method split-step --g 0 --dt 0.01 --nx 256 --xmax 8 --trap harmonic
```

Each run writes `results/summary.json`, `results/density.png`, and `results/convergence.png`. `reproduce.py` runs every supplied configuration and stores each computed set under `results/<experiment>/`. It does not download data or use pre-recorded values as solver input. The checked-in result files are reference outputs for comparison; they are regenerated by the commands above.

## SRS capture

The repository includes `.srs/project.toml`, which sets the project name and selects the result files as artifacts. After installing the SRS CLI and authenticating, initialize the checkout with `srs init`, then capture a run, for example:

```sh
srs run --experiment harmonic-reference -- python run.py \
  --method split-step --g 0 --dt 0.01 --nx 256 --xmax 8 --trap harmonic
```

The SRS fixture in this checkout is generated by `generate_demo.py`; its records preserve the public solver's repository name and commit. Scientific fact keys are chosen by the example research workflow and are not part of the SRS platform protocol.

## Numerical scope and provenance

The implementation is a compact teaching and workflow example, not a production simulator. It uses a finite interval, a uniform grid, a second-order finite-difference diagnostic, and fixed stopping criteria. Results should be checked for domain-size, grid-spacing, time-step, and method sensitivity before being used as research evidence. The harmonic reference is compared with its exact analytic value; interacting and non-harmonic cases are computed numerically and are not presented as exact benchmarks.

Source, experiment settings, and reference outputs are maintained in the public repository at [github.com/0jg/bec-ground-state](https://github.com/0jg/bec-ground-state). The fixture copy is kept in sync for the SRS demo and automated project checks.
